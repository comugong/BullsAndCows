# Bulls and Cows

Unreal Engine 5 C++를 활용해 구현한 멀티플레이어 숫자 야구 게임입니다. 서버와 클라이언트 간의 RPC 및 Replication을 활용하여 입력 처리, 턴 관리, 제한 시간, 승패 판정 등 멀티플레이어 게임의 핵심 기능을 구현했습니다.

## 🎮 프로젝트 소개

- **프로젝트명:** Bulls and Cows
- **개발 엔진:** Unreal Engine 5.6
- **개발 언어:** C++
- **게임 장르:** 멀티플레이어 숫자 야구
- **네트워크 환경:** Dedicated Server 기반 멀티플레이어 테스트

플레이어는 서버가 생성한 3자리 숫자를 추측합니다. 각 플레이어는 제한된 기회와 시간 안에 정답을 맞혀야 하며, 정답을 맞히면 승리하고 모든 플레이어가 기회를 소진하면 무승부가 됩니다.

## ✨ 주요 기능

### 1. 숫자 야구 시스템
- 서버에서 1~9 사이의 서로 다른 숫자 3개로 정답 생성
- 입력값의 형식 및 중복 숫자 검증
- Strike, Ball 판정
- 잘못된 입력은 시도 횟수를 소모하지 않도록 처리

### 2. 멀티플레이어 채팅 시스템
- 클라이언트의 입력을 Server RPC로 전달
- 서버에서 입력을 검증하고 결과 메시지 생성
- Client RPC를 통해 각 클라이언트에 메시지 전달
- 플레이어 이름과 시도 횟수를 포함한 결과 표시

### 3. 턴 및 제한 시간 시스템
- 플레이어별 턴 진행
- 턴당 10초 제한 시간
- 서버 타이머를 통한 시간 초과 처리
- 시간 초과 시 시도 횟수 차감 및 다음 턴 진행
- 현재 턴 플레이어가 아닌 경우 입력 제한

### 4. 승패 판정 및 라운드 관리
- 정답을 맞힌 플레이어의 승리 처리
- 모든 플레이어가 기회를 소진하면 무승부 처리
- 결과 메시지를 일정 시간 표시한 뒤 새 라운드 시작
- 새 정답 생성 및 플레이어별 시도 횟수 초기화

### 5. 게임 상태 동기화
- PlayerState를 통한 플레이어 정보 및 시도 횟수 관리
- GameState를 통한 현재 턴 플레이어와 턴 종료 시각 관리
- Replication을 활용한 주요 게임 상태 동기화
- 서버 권한 기반의 입력 검증 및 게임 진행 제어

## 🏗️ 주요 클래스

| 클래스 | 역할 |
|---|---|
| `ABCGameModeBase` | 정답 생성, 입력 검증, 숫자 판정, 턴 제어, 승패 판정 및 라운드 초기화 |
| `ABCGameStateBase` | 현재 턴 플레이어 및 턴 종료 시각 관리와 상태 복제 |
| `ABCPlayerState` | 플레이어 이름, 현재 시도 횟수, 최대 시도 횟수 관리 |
| `ABCPlayerController` | 클라이언트 입력 전달 및 RPC를 통한 메시지 처리 |
| `UBCChatInput` | 채팅 입력 처리 및 턴 상태에 따른 입력 활성화 |
| `UBCNotificationWidget` | 현재 턴, 남은 시간 및 상태 알림 표시 |

## 🌐 네트워크 처리 구조

게임의 핵심 판정과 진행은 서버에서 처리하도록 구성했습니다.

1. 클라이언트가 숫자를 입력합니다.
2. Server RPC를 통해 입력값을 서버로 전달합니다.
3. 서버에서 입력 유효성, 현재 턴, 제한 시간을 검사합니다.
4. 유효한 입력이면 시도 횟수를 갱신하고 결과를 판정합니다.
5. Client RPC를 통해 결과 메시지를 전달합니다.
6. Replication을 통해 공유해야 하는 게임 상태를 클라이언트에 동기화합니다.

이 구조를 통해 클라이언트의 UI 상태와 실제 게임 규칙을 분리하고, 서버를 기준으로 일관된 게임 진행을 구현했습니다.

## ▶️ 실행 방법

1. Unreal Engine 5.6과 프로젝트에 필요한 개발 환경을 준비합니다.
2. 프로젝트의 `.uproject` 파일을 Unreal Editor에서 엽니다.
3. C++ 프로젝트를 빌드합니다.
4. 멀티플레이어 테스트를 위해 Dedicated Server와 클라이언트 실행 환경을 구성합니다.
5. 여러 클라이언트를 연결하여 채팅, 턴 전환, 제한 시간, 승패 판정 및 라운드 재시작을 확인합니다.

> 실행 환경과 빌드 설정은 프로젝트 구성에 따라 달라질 수 있습니다.
